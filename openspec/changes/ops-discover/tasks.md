# Tasks

Schemat modelu jest zamrożony w `design.md` → „Model architektury (schemat)" wraz z tabelą reguł i regułami znaków. Reguły kolejności, agregacji, dopisków, atomowości i świeżości: `design.md` → decyzje 3–9. Uzgadnianie przy `--scope`: decyzja 13. Wymagania i scenariusze: `specs/architecture-discovery/spec.md`. TDD: test czerwony → kod → zielony, w obrębie każdego zadania. Każda fikstura testowa jest samodzielna — żadne zadanie nie opiera się na plikach wygenerowanych w grupie 8.
